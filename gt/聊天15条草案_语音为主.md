# 聊天 15 条草案（语音为主）—— Ground Truth 文案与录制协议

用于**交叉验证**上一版 30 条草案暴露的问题：气泡清单质量门、聊天面板次序（滚动）、收发方向一致率。
共 **15 项 = 8 条语音 + 6 条打字 + 1 个表情包**。

约定：**A ＝ 手机①**（被录制，屏上靠右/绿色气泡）；**B ＝ 手机②**（对端，屏上靠左/白色气泡）。

## 3. 录制协议

1. **从空白会话开始**：先清空该好友聊天记录，录屏里出现的必须正好是这 15 项。
2. **浅色模式**：语音气泡检测依赖"绿气泡（右/发）/ 白气泡（左/收）"的颜色分域，深色模式会失效。
   同时关自动亮度、关自动旋转、关护眼模式，全程不改字号与主题。
3. **开勿扰模式**：横幅通知会遮住一行，直接造成漏检。
4. **模式 B（音频侧要能跑）**：微信 → 设置 → 聊天 → 关掉"使用听筒播放语音"；
   媒体音量拉满；**发完一条语音后立刻点一下气泡外放播放**，播完再发下一条。
   录制时**打开麦克风**，环境安静。
5. **节奏**：每条发完**等 ≥2 秒**再发下一条（录音浮层撤掉、气泡静止后才算干净画面）；
   打字消息发完**收起键盘**（点聊天区空白）再等 ≥2 秒。整体固定 3 秒/项。
6. **语音指法**：按住说 → 说清楚 → 直接松手发送。**不要上滑取消**，不要在"取消"附近松手。
   单条控制在 **2–8 秒**（别超 10 秒），吐字清晰、语速正常、离嘴 10–20cm。
7. **滚动相位**：#10 之后上滑到顶部，再**慢速分段**滚回最新（每段停 1 秒），之后继续 #11–#15。
   滚动时**不要长按消息、不要触发"引用/转发"菜单**。

## 4. 本份 label 的考点

| 考点 | 条目 | 观察指标 |
|---|---|---|
| 短文本被误判成语音气泡 | #2 #3 #9 | 气泡清单里是否混入右侧短文本；方向是否被带偏 |
| 同侧相邻近重复 | #2 #3 | 是否被合并成一条、或互相吞并 |
| 模板近重复（差 1 位数字） | #6 #8 | 是否被误并；是否漏掉其中一条 |
| 滚动后的聊天次序 | 全局（#10 之后） | 输出行序是否与 #1→#15 一致 |
| 收发方向 | #4 #5 #9 #13 | `[发]/[收]` 与 sender 是否一致（A=发, B=收） |
| 极短语音 | #9 | 是否被质量门误剔除 |
| 折行长文本 | #15 | 是否被拆成 3 条独立消息 |
| 无文字表情包 | #10 | 不得产出任何文本 |
| 中英混排 / URL | #12 #13 #14 | 数字与英文是否完好 |
